## What I learned

Creating the resource group first, before any billable resource, means everything can be
deleted in one action at the end — nothing is left orphaned, which makes control over what
exists a lot easier. The budget is a monitoring tool, not a limit: it does not block spending,
but it gives visibility into where we stand financially — or however else we choose to define
that view — which matters given the 30-day credit window.
